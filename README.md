## 1. Security Hierarchy

- **CEO:** Oversees overall business objectives.
- **CISO:** Leads cybersecurity strategy and makes key security decisions.
- **Red Team:** Performs offensive security testing.
- **Blue Team:** Protects systems and detects cyber threats.
- **GRC Team:** Manages security policies, risk, and compliance.

## 2. Blue Team Departments

| Department | Responsibilities |
|---|---|
| SOC | Monitors alerts and investigates threats. |
| CIRT | Handles major security incidents and breaches. |
| Digital Forensics | Examines digital evidence. |
| Threat Intelligence | Researches threat actors and emerging threats. |
| Threat Hunting | Proactively searches for hidden attackers. |

## 3. SOC Career Structure

- **SOC L1:** Monitors and triages alerts, escalating complex cases.
- **SOC L2:** Performs deeper investigations.
- **SOC Engineer:** Configures and maintains SIEM, EDR, and security tools.
- **SOC Manager:** Manages SOC operations and performance.

## 4. Internal SOC vs MSSP

| Internal SOC | MSSP |
|---|---|
| Protects one organization. | Provides security services to multiple clients. |
| Usually works with fewer tools. | Uses different tools for different clients. |
| Focuses on its organization's infrastructure. | Often handles a larger variety of incidents. |

**MSSP:** Managed Security Service Provider.

## 5. Career Progression

A typical SOC career path:

`SOC L1 → SOC L2 → SOC L3 / Specialist`

Possible specializations include:

- Incident Response
- Threat Hunting
- Malware Analysis
- Digital Forensics
- Detection Engineering
- Threat Intelligence

## 6. Key Takeaways

- The CISO oversees an organization's cybersecurity strategy.
- Blue Team focuses on defensive security.
- CIRT handles critical security incidents.
- MSSPs provide outsourced SOC services.
- SOC L2 is a natural progression from SOC L1.
- Thinking like an attacker helps defenders identify threats.
